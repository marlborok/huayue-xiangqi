# 花月象棋

為親子對弈設計的 3D 中國象棋網頁遊戲。紅方是「花之國」，黑方是「月之國」，所有棋子都是擬人化的女孩角色。

## 執行方式

純前端，不需要建置步驟。

- 本機：在專案資料夾執行 `python3 -m http.server 8000`，再打開 `http://localhost:8000`
  （直接雙擊 `index.html` 也能開，但部分瀏覽器會擋本機檔案，建議用本機伺服器）
- 部署：推到 GitHub 後，在 repo 的 Settings › Pages 選擇從 `main` 分支根目錄發布

## 專案結構

```
index.html        頁面骨架、按鈕、載入順序
css/style.css     介面樣式
js/rules.js       象棋規則（純邏輯，不含畫面）：走法、將軍、將帥不照面、無路可走判負
js/figures.js     角色模型（目前是幾何形狀的暫代版）與頭頂徽章貼圖
js/game.js        3D 場景、點選與走棋、鏡頭、特寫演出、介面
```

外部套件：three.js r128 與 OrbitControls（從 CDN 載入）、Google Fonts 的霞鶩文楷 TC 與 Noto Sans TC。

## 初版功能

- 完整象棋規則：蹩馬腿、塞象眼、炮隔子吃、將帥不照面、不能送將、無路可走判負
- 3D 角色面向敵陣、微微前傾；頭頂浮空徽章顯示棋子文字，正俯視也能辨識，字的方向朝向自己的玩家
- 點選棋子顯示可走位置（金點）與可吃的棋子（紅圈）
- 角色說明氣泡：用角色口吻說明走法
- 精彩特寫：吃子、將軍、獲勝時鏡頭從角色正面拉近演出，徽章自動淡出
- 鏡頭：近俯視（預設）、正俯視、從對面看；可拖曳旋轉、縮放欣賞角色，「回到棋盤」一鍵復位
- 自動轉向（預設關閉，面對面下棋時不需要）
- 悔棋不限次數、重新開始需按兩次確認
