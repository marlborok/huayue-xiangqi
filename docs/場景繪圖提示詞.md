# 花月象棋：場景造景的繪圖提示詞（第三階段）

把棋盤外的 3D 造景（樹、亭子、山丘……）換成和角色同一套畫風的紙偶插畫。
用法和 `角色繪圖提示詞.md` 一樣：每張 = **共用風格** + **造景描述**。
**請把一張角色插畫（例如 帥）當參考圖附上**，畫風才會一致。

---

## 一、共用風格（每張都貼在最前面）

```
Children's picture-book illustration, soft watercolor and colored pencil, warm pastel palette,
gentle hand-drawn outlines, visible paper texture. Same art style as the reference image.
A single scenery object, seen from the front at eye level, whole object visible, nothing cropped.
Simple clear silhouette. Plain flat white background, no ground, no grass, no shadow on the floor,
no characters, no text.
```

**重點**
- **只畫一件東西、不要地面**：去背後立在場景裡，地面由遊戲畫。
- **正面、平視**：紙偶會轉向鏡頭，正面圖最自然。
- **不要人物**：角色已經在棋盤上了。

## 四、選配：天空背景（第四階段）

```
Children's picture-book watercolor landscape, very wide panorama, soft pastel,
visible paper texture, no characters, no text. Same art style as the reference image.
```
- `sky-flower.png`：`A distant spring garden: rolling pastel hills, cherry trees, a warm sunny sky with soft clouds.`
- `sky-moon.png`：`A distant night landscape: lavender hills, a big crescent moon, a starry navy sky.`

天空要寬幅（例如 2:1 或更寬），不用去背。

---

## 五、檔案

- 去背後存 PNG，長邊 800 px 左右即可（天空背景 2000 px 寬）。
- 放進新資料夾 `花之國場景/`、`月之國場景/`（或直接用上面的檔名），跟我說，我來去背並換上。
- 沒去背也行，純白背景我用程式處理。
