# 花月象棋：角色表情與兵卒成長的繪圖提示詞

遊戲已經準備好：圖一放進來就會自動用上，**缺哪張就沿用原本的圖**，所以可以慢慢補。

## 一、要畫什麼

每個角色兩種表情，加上兩國的兵卒「成長版」：

| 檔名（花之國／月之國） | 什麼時候出現 |
|---|---|
| `flower-K-worry` ／ `moon-K-worry` 等 | **緊張**：被對方瞄準、公主被將軍時 |
| `flower-K-happy` ／ `moon-K-happy` 等 | **得意／開心**：剛吃掉對手、贏了的時候 |
| `flower-P-up` ／ `moon-P-up` | **兵卒過河後的成長版**（過河就換成這張） |

角色代號：K 帥將、A 仕士、B 相象、R 俥車、N 傌馬、C 炮包、P 兵卒。
全部做完是 14 × 2 + 2 = **30 張**。建議先做這 8 張，效果最明顯：

1. `flower-K-worry`、`moon-K-worry`（公主被將軍）
2. `flower-K-happy`、`moon-K-happy`（贏了）
3. `flower-P-up`、`moon-P-up`（兵卒成長）
4. `flower-R-happy`、`moon-R-happy`（騎士吃子最常見）

## 二、怎麼產

**一定要附上該角色原本的圖當參考圖**，並在提示詞最前面寫：

```
Same character, same outfit, same art style, same proportions and same pose as the reference image.
Children's picture-book illustration, soft watercolor and colored pencil, plain flat white background,
full body, nothing cropped, no ground, no text. Only change the facial expression and a small gesture:
```

再接一句表情描述：

**緊張（worry）**
```
worried and a little scared: eyebrows raised, small open mouth, eyes looking to the side,
hands held close to her chest, a single small sweat drop.
```

**得意／開心（happy）**
```
proud and delighted: big bright smile with closed happy eyes, rosy cheeks,
one hand raised in a little cheer or victory pose.
```

**兵卒成長版（P-up）**：不是換表情，是升級造型
- 花之國 小花仙：
  ```
  The same little flower fairy, now grown braver after crossing the river: a bigger crown of
  blooming flowers, a small pink cape, holding her flower staff up high, confident smile.
  ```
- 月之國 小星精：
  ```
  The same little star sprite, now grown braver after crossing the river: a glowing star tiara,
  a small lavender cape with stars, holding a star wand up high, confident smile.
  ```

## 三、放到哪裡

- 原圖放進 `花之國/`、`月之國/` 資料夾（跟之前一樣），檔名照上表，例如 `flower-K-worry.jpg`。
- 跟我說一聲，我來去背、壓縮成 WebP、放進 `assets/paper/`，並加進離線清單。
